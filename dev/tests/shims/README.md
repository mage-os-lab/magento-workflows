# Standalone-runner shims

Minimal stand-ins for third-party classes (`Magento\...`, `Psr\Log\...`, `MageOS\AsyncEvents\...`, `CloudEvents\...`) that the unit tests reference but that are not installed in the zero-dependency standalone environment. They are loaded **only** by `dev/tests/standalone-runner.php`, via an autoloader registered *last* in the autoload chain: each file mirrors its class's PSR-4 path under this directory and is required lazily, only when no earlier autoloader (i.e. a real Composer install of Magento/psr-log) can supply the class. Real Magento installations and real PHPUnit runs therefore never load these files, and the shims deliberately implement only the minimum surface the tests exercise — anything touching real infrastructure (e.g. `ResourceConnection`) throws unless a test overrides it.
